# App improvements

This version focuses on everyday workout use. Installation can wait.

- **Previous-session autofill:** starting a routine copies the previous working sets' loads and reps, with every set marked incomplete. Routine set counts remain in control. “Copy last completed sets” also lets you bring back the full previous set list, including labeled warmups, after confirming replacement.
- **Warmup labels:** add a warmup or tap a set's type to switch between working set and warmup. Completed warmups appear in history but are excluded from personal records, strength charts, progression rules, and working-set totals.
- **Edit completed workouts:** open a session in History and choose Edit workout. Correct loads/reps, mark sets complete/incomplete, change set types, add/remove sets, adjust the session name and date/time, or add notes. Save changes explicitly; cancel leaves the saved workout intact. Charts and recommendations use the corrected data. Backdating reorders history by workout date.
- **Session notes:** record how a workout felt. Notes on an active session autosave; notes edited in History save with the rest of that draft.
- **Backup reminders:** after your first session, Train shows a reminder until you export. It reappears after seven days. This records when an export was requested; the app cannot confirm that you saved the downloaded file.
- **Existing data:** older version-1 backups remain compatible. Sets without a warmup label are treated as working sets.

The app remains free, offline-capable, and private to your browser. No service accounts, external libraries, analytics, or paid APIs were added.
